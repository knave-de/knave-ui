# Agent instructions

- Define colors and other visual design values in `.css` files instead of
  hardcoding them in Rust or other application code.
- Create or switch to a dedicated branch before making changes. Do not work
  directly on `master`.
- Use Conventional Commits.
- Test changes thoroughly before creating a pull request. Run the relevant
  tests and checks, and verify any affected behavior.
- Only merge when explicitly requested. Use squash merging, then delete the
  merged branch.
